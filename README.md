# Informes QSQS · Villa de San Andrés

Consulta de los informes 2026 de la Institución Educativa Villa de San Andrés, Aguachica, Cesar. Código DANE: **220011001254**.

- `index.html`: página de acceso.
- `academico.html`: informe académico A1–A2 original.
- `dse.html`: informe DSE A1 original.
- `.nojekyll`: permite servir los archivos estáticos sin procesamiento Jekyll.

Los informes contienen datos agregados por establecimiento y grado. Se conservan sin modificaciones. Esta página facilita la consulta institucional; no es un portal oficial del Ministerio de Educación Nacional.

## Publicar en GitHub Pages

1. Crear o abrir el repositorio de destino en la cuenta `juanjoweb`.
2. Subir estos archivos a la raíz de la rama `main`, manteniendo sus nombres.
3. En **Settings → Pages → Build and deployment**, seleccionar **Deploy from a branch**.
4. Seleccionar la rama **main** y la carpeta **/(root)**; guardar.
5. Esperar a que GitHub muestre el enlace publicado y comprobar ambos informes desde ese enlace.

La publicación en GitHub Pages permite que cualquier persona con acceso a internet consulte los informes. No incluye contraseña ni control de acceso.

Para una consulta local, abrir `index.html` con un navegador y conservar los dos informes junto a él. No requiere Excel ni instalación de dependencias.
